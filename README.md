# KiddoCalc 🌈 Kalkulator Ceria & Lucu untuk Anak-Anak 🐱✨

Aplikasi kalkulator interaktif dengan desain visual **Cute & Colorful** bertema permen pastel yang dirancang khusus untuk membuat proses belajar berhitung dan matematika menjadi sangat menyenangkan bagi anak-anak!

---

## ✨ Fitur-Fitur Seru & Edukatif

1. **🎨 Tampilan Visual Super Cute & Colorful**:
   - Palet warna ceria permen pastel (*Strawberry Pink, Sunshine Yellow, Bubble Blue, Mint Green, Lavender*).
   - Tombol kalkulator tebal bergaya **3D Candy** dengan efek pantul empuk saat ditekan.
   - Tipografi ramah anak menggunakan font *Fredoka* & *Quicksand*.
   - Responsif sempurna untuk semua ukuran layar: smartphone (mobile), tablet/iPad, hingga layar monitor komputer (desktop).

2. **🐱 Maskot Hewan Lucu Interaktif**:
   - Pilihan 3 karakter maskot: **Kiki Kucing 🐱**, **Bubu Kelinci 🐰**, dan **Bobi Beruang 🐻** (cukup klik tombol ganti di bawah maskot!).
   - Ekspresi wajah dinamis: tersenyum senang (*idle*), berpikir penasaran (*thinking*), bersorak gembira (*cheering*), dan kaget lucu (*surprised*).
   - Balon percakapan dengan kata-kata penyemangat positif bagi anak.

3. **🎵 Efek Suara Xylophone / Kolintang Asli (Web Audio API)**:
   - Setiap angka (0-9) menghasilkan nada kolintang yang jernih, nyaring, dan harmonis!
   - Efek suara kartun bertenaga (*dual-oscillator*) untuk tombol operasi (+, -, ×, ÷, kurung).
   - Efek suara *bloop* saat menghapus layar.
   - Jingle kemenangan ceria dan letupan **hujan konfeti warna-warni (*Confetti*)** saat menekan tombol sama dengan (`=`).
   - Tersedia tombol **Mute / Unmute** jika ingin mode tenang.

4. **🍎 Alat Bantu Hitung Visual Benda Nyata (Visual Math Aid)**:
   - Di bawah layar kalkulator, anak dapat melihat representasi nyata dari angka berupa benda/buah yang membal-membal (Apel 🍎, Bintang ⭐️, Permen 🍭, Balon 🎈, atau Kucing 🐱).
   - Membantu anak memahami konsep kuantitas dan bilangan secara konkret.

5. **🔊 Suara Pelafalan Angka (Voice Speech)**:
   - Dilengkapi fitur suara pembaca angka berbahasa Indonesia menggunakan Web Speech API (bisa diaktifkan melalui tombol mikrofon di pojok kanan atas).

6. **🎯 Mode Kuis Pintar (Math Quiz Challenge)**:
   - Mini game tantangan berhitung interaktif dengan level Mudah (1-10), Sedang (1-20), dan Perkalian.
   - Mengumpulkan bintang skor prestasi atas setiap jawaban benar.

7. **📖 Buku Catatan Hitungan (History)**:
   - Menyimpan riwayat perhitungan sebelumnya yang bisa ditinjau kembali atau dimasukkan ulang ke kalkulator.

## 📖 Panduan Lengkap Penggunaan Kalkulator

### 1. Berhitung Dasar
- **Mengetik Angka**: Tekan tombol angka warna-warni (0–9) untuk memasukkan nilai. Setiap angka akan memainkan nada musik kolintang.
- **Operasi Matematika**:
  - `+` (Tambah): Untuk menjumlahkan.
  - `-` (Kurang): Untuk mengurangkan.
  - `×` (Kali): Untuk mengalikan.
  - `÷` (Bagi): Untuk membagi.
  - `(` dan `)` (Kurung): Untuk pengelompokan hitungan prioritas.
- **Melihat Hasil (`=`)**: Tekan tombol hasil berwarna pink cerah untuk melihat jawaban. Jika rumus benar, konfeti pesta akan meletup dan maskot akan bersorak gembira!
- **Menghapus Layar (`C`)**: Tekan tombol merah `C` untuk membersihkan layar kalkulator.
- **Hapus Satu Angka**: Tekan ikon tempat sampah kecil di pojok kanan atas layar display.

### 2. Mengganti Teman Maskot
- Klik tombol berbentuk pil **[ Ganti Teman: Kiki 🐱 🔄 ]** di bawah kepala maskot untuk berganti teman belajar antara **Kiki Kucing 🐱**, **Bubu Kelinci 🐰**, atau **Bobi Beruang 🐻**.

### 3. Menggunakan Alat Bantu Hitung Visual
- Setiap mengetik angka antara 1 sampai 20, benda-benda lucu sejumlah angka tersebut akan muncul membal-membal di bawah layar.
- Klik tombol **`Ganti: [Icon]`** untuk mengubah jenis benda:
  - 🍎 Apel
  - ⭐️ Bintang
  - 🍭 Permen
  - 🎈 Balon
  - 🐱 Kucing

### 4. Pengaturan Suara & Pelafalan
- **Ikon Speaker 🔊**: Klik untuk mematikan/menghidupkan musik kolintang dan efek suara kartun.
- **Ikon Mikrofon 🎙️**: Klik untuk menyalakan suara robot pintar yang membacakan angka dan operasi hitung dalam Bahasa Indonesia.

### 5. Bermain Kuis Matematika Pintar
- Klik tombol **`Kuis`** di pojok kanan atas.
- Pilih tingkat kesulitan:
  - **Mudah 🌱**: Penjumlahan angka 1–10 dengan bantuan visual buah apel.
  - **Sedang 🚀**: Penjumlahan dan pengurangan angka 1–20.
  - **Perkalian 🍭**: Tabel perkalian angka 2–5.
- Masukkan jawaban pada kotak dan klik **Cek! 🎯**. Kumpulkan bintang skor sebanyak-banyaknya!
- Ingin menghitung soal kuis di layar kalkulator? Klik tulisan *"Hitung di Layar Kalkulator 📱"*.

### 6. Melihat Buku Catatan Hitungan (Riwayat)
- Klik tombol ikon buku **📖** di pojok kanan atas untuk melihat riwayat perhitungan sebelumnya.
- Klik salah satu riwayat untuk menggunakan kembali angkanya di kalkulator.

### 7. Shortcut Keyboard Komputer / Laptop
Anda juga dapat menggunakan keyboard fisik:
- **`0` – `9`**: Mengetik angka
- **`+`**, **`-`**, **`*`**, **`/`**: Operasi matematika
- **`Enter`** atau **`=`**: Menghitung hasil
- **`Backspace`**: Menghapus satu karakter
- **`Escape`** atau **`C`**: Mereset/menghapus layar

## 🛠️ Teknologi yang Digunakan

- **React 18**
- **Vite 5** (Fast Build & Instant HMR)
- **Tailwind CSS** (Custom Kiddo pastel animations & styles)
- **Lucide React** (Ikon modern & konsisten)
- **Canvas Confetti** (Efek selebrasi juara)
- **Web Audio API** (Sintesis suara musik kolintang & suara kartun tanpa audio eksternal)
- **Web Speech API** (Pelafalan suara angka berbahasa Indonesia)

## 🚀 Cara Menjalankan Proyek

Buka terminal (PowerShell / Command Prompt) di dalam folder proyek ini:

### 1. Install Dependensi (Build `node_modules`)
```bash
npm install
```

### 2. Jalankan Mode Development
```bash
npm run dev
```

Aplikasi akan otomatis berjalan dan dapat dibuka di browser:
👉 **`http://localhost:3000`**

### 3. Build untuk Produksi
```bash
npm run build
```
Hasil build siap rilis akan disimpan di dalam folder `dist/`.
